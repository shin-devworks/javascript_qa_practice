## 01 期待結果と実際の結果を比較

期待する画面表示と、実際の画面表示が一致するか判定します。

### 実行方法

```bash
node 01_compare_results.js
```

### 確認結果

- `expected` と `actual` がともに「訪問成功」：合格と表示
- `actual` を「判定できません」に変更：不合格と表示

※画面表示を自動取得するプログラムではなく、入力した2つの値を比較する練習です。

## 02 複数項目の結果を確認

3つの確認項目について、期待値と実際の値を順番に比較し、結果を表示します。

### 実行方法

```bash
node 02_check_app.js
```

### 確認結果

- 「同日再訪問」の実際の値を「カウントした」にした場合：2/3件合格
- 実際の値を「カウントしない」に変更した場合：3/3件合格
- 不合格の場合は、項目名に加えて期待値と実際の値を表示できた

※実際のアプリから表示や動作を取得するプログラムではなく、コード内に用意した値を比較する基礎練習です。
